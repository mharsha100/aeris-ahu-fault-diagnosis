GOVERN · MAP · MEASURE · MANAGE

Trust has evidence.

Each control has a test, a metric, and a remaining limitation.

Input & scope

Shape, finite values, physical bounds, timestamps, fan and occupancy checks. Unknown or unverified contexts require review. Validated adaptation inputs also pass confidence, branch agreement and sensor-range checks.

Reviewed model changes

Versioned artifacts, integrity checks, three-seed comparisons, per-class recall and missed-fault checks. Failed candidates do not replace parents.

Auditable feedback

SQLite prediction IDs, unique requests, review history and provenance. Test opinions are separated from real inspected outcomes.

What production readiness still requires

Independent site validation, representative verified outcomes, authenticated access and TLS before wider exposure, an operational owner and response process, and a tested backup/restore policy. A strong offline score does not replace these requirements.

Why a value may be unavailable

No recent requests: latency quantiles need requests in the selected time range. Make a diagnosis to create real traffic.

No agreement responses: agree / (agree + disagree) is undefined when both counts are zero; unsure is reported separately.

No independently inspected labels: live accuracy and recall cannot be measured yet. Test feedback cannot fill this gap.

Limited independent cases: offline recording counts do not establish performance at a new building. More windows from the same recording do not fix this.
