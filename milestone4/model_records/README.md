# Preserved M4 model records

Exact model-metadata release files are mirrored here so GitHub reviewers can inspect all three 50-epoch training histories, configurations, stage outcomes, and selected temporal checkpoints. Their original runtime paths are `data/aeris_models/<bundle>/...`; this directory is an evidence mirror, not the runtime model directory. Forest weights, prepared input packs, and raw datasets remain outside Git. The original release downloads and reproduction commands are documented in the project README.
